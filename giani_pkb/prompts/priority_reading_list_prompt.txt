Available Documents:
{document_context}

- **High-Priority**: Documents essential for understanding the project mandate, core objectives, and immediate next steps
- **Medium-Priority**: Documents that provide valuable context but are not immediately critical for onboarding

JSON OUTPUT STRUCTURE:
Generate a JSON object with key `priorityReadingList` containing:

1. **`highPriority`**: List of 2-4 document objects with keys:
   - `documentId`: Document identifier (use the document number from context)

   - `documentSourceType`: Source type
   - `reasonForPriority`: One-sentence justification for why this is a must-read

2. **`mediumPriority`**: List of 4-6 document objects with same structure as above
   - Focus on documents that provide valuable supplementary context
