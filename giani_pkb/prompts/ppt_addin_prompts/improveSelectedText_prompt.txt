4.  **Incorporate Context:** Ensure the refined text fits naturally with the `currentSlideStatement` and `immediatelyPreviousTextSnippet`.

OUTPUT FORMAT:
Return a simple list of plain strings, where each string is a refined version of the `selectedTextContent`.
